# AETHER PROTOCOL // 3D Siber Taktik FPS

Tarayıcıda doğrudan çift tıklayarak (`index.html`) çalıştırılabilen, **Three.js WebGL2 PBR**, **ACES Filmic Tone Mapping**, **UnrealBloomPostProcessing** ve **Prosedürel Konvolüsyon Yankılı Web Audio** motorlarıyla geliştirilmiş 3B bilim-kurgu FPS oyunu.

## Nasıl Çalıştırılır?
Herhangi bir kurulum veya sunucu gerekmez (Three.js CDN üzerinden yüklenir, tüm PBR dokular ve sesler gerçek zamanlı üretilir):
1. `index.html` dosyasına çift tıklayarak modern bir tarayıcıda (Chrome, Edge, Brave, Firefox) açın.
2. Grafik kalitesini (**Ultra / Yüksek / Orta**) ve fare hassasiyetini seçip **OPERASYONU BAŞLAT** butonuna tıklayın.

## Kontroller
- **WASD + Sol Shift**: Hareket ve Taktik Koşu
- **Sol Tık / Sağ Tık**: Ateş Et / Holografik Nişangâh (ADS)
- **Space (x2)**: Zıplama ve Exo-İtici Çift Zıplama
- **C / Sol Ctrl / Q**: Yerde Kayma (Slide) veya Havada Atılma (Air-Dash)
- **F veya E**: Kronos Zaman Yavaşlatma (Bullet-Time)
- **G**: Fiziksel Sekmeli Plazma El Bombası
- **T**: Otonom Lazer Taret Kurulumu
- **1 / 2 / 3 / Fare Tekerleği**: Silah Değiştir (`Vortex AR-9`, `Titan SG-4`, `Hyperion Railgun`)
- **R**: Şarjör Değiştir
- **B veya Tab**: Exo-Zırh Cephaneliği ve Kalıcı Yükseltmeler
